About this roll

What this set of runs supports, and what it does not.

    What stays identical

    So the only variables left are the model and how long it thinks.

    • Prompt The same one-shot brief, frozen before the first run.
    • Starter The same clean starter repository.
    • Environment The same tools, permissions, time and network policy.
    • Steering No follow-up messages, corrections, or human repair.
    • Session A new session each time, finishing with a runnable build.
    • Review One frozen review instrument, fixed after three blind calibration passes.

    Reading a frame

    The score reviews engineering. It does not score how the app looks.

    • Look first Hierarchy, polish, useful states, coherent decisions.
    • Then ask Whether the extra time and tokens showed up on screen.
    • Remember One run is evidence, not a ranking.

    What a credit is

    Credits are the billing unit applied to token usage. Plan allowances are a measured snapshot, not a fixed quota.
